# C++ algorithm Library

The `<algorithm>` library has many functions that allow you to modify ranges of data from data structures.

A list of useful functions in the algorithm library can be found below.

| Function                                                     | Description                                                  |
| ------------------------------------------------------------ | ------------------------------------------------------------ |
| [adjacent_find()](https://w3schools.dev/cpp/ref_algorithm_adjacent_find.asp) | Finds a pair of consecutive elements with the same value in a data range |
| [all_of()](https://w3schools.dev/cpp/ref_algorithm_all_of.asp) | Checks if all of the elements in a data range match a condition |
| [any_of()](https://w3schools.dev/cpp/ref_algorithm_any_of.asp) | Checks if at least one element in a data range matches a condition |
| [binary_search()](https://w3schools.dev/cpp/ref_algorithm_binary_search.asp) | An efficient algorithm for finding if a value exists in a sorted data range |
| [copy()](https://w3schools.dev/cpp/ref_algorithm_copy.asp)   | Copies the values from a data range into a different data range |
| [count()](https://w3schools.dev/cpp/ref_algorithm_count.asp) | Counts the number of times that a value occurs in a data range |
| [count_if()](https://w3schools.dev/cpp/ref_algorithm_count_if.asp) | Counts the number of elements in a data range that match a condition |
| [fill()](https://w3schools.dev/cpp/ref_algorithm_fill.asp)   | Writes a value into every element of a data range            |
| [find()](https://w3schools.dev/cpp/ref_algorithm_find.asp)   | Finds the first element of a data range with a specified value |
| [find_first_of()](https://w3schools.dev/cpp/ref_algorithm_find_first_of.asp) | Finds the first element of a data range which matches one of several specified values |
| [find_if()](https://w3schools.dev/cpp/ref_algorithm_find_if.asp) | Finds the first element of a data range which matches a condition |
| [find_if_not()](https://w3schools.dev/cpp/ref_algorithm_find_if_not.asp) | Finds the first element of a data range which does not match a condition |
| [for_each()](https://w3schools.dev/cpp/ref_algorithm_for_each.asp) | Runs a function on every element in a data range             |
| [includes()](https://w3schools.dev/cpp/ref_algorithm_includes.asp) | Checks if all of the values in a sorted data range exist in another sorted data range |
| [is_permutation()](https://w3schools.dev/cpp/ref_algorithm_is_permutation.asp) | Checks if a data range is a permutation of another           |
| [is_sorted()](https://w3schools.dev/cpp/ref_algorithm_is_sorted.asp) | Checks if a data range is sorted                             |
| [is_sorted_until()](https://w3schools.dev/cpp/ref_algorithm_is_sorted_until.asp) | Finds the position in a data range at which elements are no longer sorted |
| [lower_bound()](https://w3schools.dev/cpp/ref_algorithm_lower_bound.asp) | Finds the first element at or above a specified lower bound in a sorted data range |
| [max_element()](https://w3schools.dev/cpp/ref_algorithm_max_element.asp) | Finds the element with the highest value in a data range     |
| [merge()](https://w3schools.dev/cpp/ref_algorithm_merge.asp) | Merges the values of two data ranges into a new data range   |
| [min_element()](https://w3schools.dev/cpp/ref_algorithm_min_element.asp) | Finds the element with the lowest value in a data range      |
| [none_of()](https://w3schools.dev/cpp/ref_algorithm_none_of.asp) | Checks if none of the elements in a data range match a condition |
| [random_shuffle()](https://w3schools.dev/cpp/ref_algorithm_random_shuffle.asp) | Randomly rearranges the elements in a data range             |
| [replace()](https://w3schools.dev/cpp/ref_algorithm_replace.asp) | Replaces all occurrences of a value in a data range with a different value |
| [replace_copy()](https://w3schools.dev/cpp/ref_algorithm_replace_copy.asp) | Creates a copy of a data range with all occurrences of a specified value replaced with a different value |
| [replace_copy_if()](https://w3schools.dev/cpp/ref_algorithm_replace_copy_if.asp) | Creates a copy of a data rage where all values that match a condition are replaced with a different value |
| [replace_if()](https://w3schools.dev/cpp/ref_algorithm_replace_if.asp) | Replaces all values in a data range that match a condition with a different value |
| [reverse()](https://w3schools.dev/cpp/ref_algorithm_reverse.asp) | Reverses the order of elements in a data range               |
| [reverse_copy()](https://w3schools.dev/cpp/ref_algorithm_reverse_copy.asp) | Creates a copy of a data range with the elements in reverse order |
| [search()](https://w3schools.dev/cpp/ref_algorithm_search.asp) | Finds a specified sequence of values in a data range         |
| [sort()](https://w3schools.dev/cpp/ref_algorithm_sort.asp)   | Sorts the values of a data range in ascending order          |
| [swap()](https://w3schools.dev/cpp/ref_algorithm_swap.asp)   | Swaps the values of two variables                            |
| [swap_ranges()](https://w3schools.dev/cpp/ref_algorithm_swap_ranges.asp) | Swaps the values of two data ranges of the same size         |
| [upper_bound()](https://w3schools.dev/cpp/ref_algorithm_upper_bound.asp) | Finds the first element above a specified upper bound in a sorted data range |
